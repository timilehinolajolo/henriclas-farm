# Henri Clas Integrated Farms

An enterprise website and digital storefront for **Henri Clas Integrated Farms**, an integrated multi-sector farm located in Isefun Ipaja, Alimosho, Lagos State. 

The platform showcases the farm's five core operational sectors: Catfish, Grasscutter, Rabbit, Poultry, and an on-site Feed Mill.

---

## Project Overview & Upgrades

This repository has been upgraded from a vanilla HTML/JS setup to a modern, type-safe development environment powered by **TypeScript** and **Vite**.

* **TypeScript Migration:** All browser scripts are type-checked and compiled securely via `src/main.ts`.
* **Multi-Page Architecture:** Retains clean, dedicated pages for Home, About, Products, and Contact while benefiting from lightning-fast module bundling.
* **Refined Design System:** Built using modern CSS variables, CSS grid/flexbox layouts, custom typography (`Fraunces`, `Work Sans`, `JetBrains Mono`), and enhanced responsive viewports.
